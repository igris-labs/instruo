## Usage

Choose a browser-decodable image up to 25 MB and 40 megapixels. Inspect supported EXIF fields, including camera, date, and GPS information when available. Copy the metadata or download a clean PNG. Clean export redraws the visible image without copying EXIF; the original file is not changed. Animation and original compression are not preserved.

## Privacy

The file stays in your browser.
