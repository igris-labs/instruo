## Convert without changing the original

Choose an image, select WebP, PNG or JPEG, then convert and download the result. The original file is not overwritten. Conversion preserves the image dimensions.

PNG and WebP support transparent backgrounds. JPEG fills transparent areas with white. Animated images export a single frame; SVG inputs are rasterized.

## Files stay on your device

Conversion runs in this tab. Files must be no larger than 25 MB or 40 megapixels. If a file cannot be decoded or a format is unsupported, choose another file or output format.
