## Convert config safely

Paste configuration data, choose a direction and indentation, then copy or download the result. Swap direction to convert the output back. Each input is limited to 1 MB.

Conversion preserves values, not YAML comments or formatting. Duplicate keys, unsupported tags, cycles and values JSON cannot represent are reported. Quote YAML integers beyond JavaScript's safe numeric range to preserve them as strings.
