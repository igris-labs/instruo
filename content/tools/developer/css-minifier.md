## Compact stylesheet output

Paste CSS or open a local file, then choose Minify or Format. Minification uses a CSS parser with rule restructuring disabled, preserving strings and required expression whitespace. Important comments may remain. Copy or download the result and compare byte counts. Keep a readable source copy; documents are limited to 2 MB.

## Privacy

CSS stays in this browser tab.
