## Convert CSS colors

Paste a CSS color, use the color picker, or try a sample. The swatch updates immediately. Copy individual formats or all values together.

Alpha is preserved. HEX, RGB, and HSL output use sRGB; colors outside that gamut are clipped and clearly marked. Wide-gamut formats retain the source color. CSS output is rounded to five decimal places for practical use.

## Privacy

Color values are calculated locally.
