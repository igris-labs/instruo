## Make queries easier to scan

Paste a query or open a local file. Choose Standard SQL, PostgreSQL, MySQL, SQLite, SQL Server or BigQuery, then choose indentation. Formatting preserves quoted values and runs in a background worker without executing your query.

Copy or download the output. A formatted query is not proof that it is valid for your database or safe to execute. Documents are limited to 2 MB.

## Privacy

Formatting happens in the browser. Your query never leaves this device.
