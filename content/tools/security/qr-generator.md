## Create and customize

Choose the content type and enter its details. The preview updates automatically. Adjust foreground/background colors, PNG size, quiet zone, and error correction. Export PNG for a fixed-size image or SVG for scalable print artwork.

Keep a quiet zone of at least four modules. Dark codes on light backgrounds scan most reliably. Error-correction percentages are approximate recovery levels, not a promise that a damaged or customized code will scan. Test the downloaded code on your target devices before printing or sharing it.

## Privacy and sharing

QR content stays in this tab and is not uploaded. A downloaded Wi-Fi code contains the network credentials: anyone who can scan it can read those details. These are static codes; changing this tool's input does not change an already downloaded image.
